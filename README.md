# Abhinav Ray Portfolio

A clean static portfolio website showcasing projects, skills, education, and contact details.

## Live Demo

[View the live site](https://abhinavray07.github.io/portfolio/)

## Pages

- `index.html` — Home page with profile summary, quick links, and highlights.
- `about.html` — About section describing background and interests.
- `education.html` — Academic history and coursework.
- `skills.html` — Technical skills and domain strengths.
- `projects.html` — Project showcase with GitHub links.
- `contact.html` — Contact information and online profiles.

## Features

- Lightweight static website built with HTML and CSS.
- Dark theme with high contrast accent colors.
- Responsive layout for small screens.
- Simple navigation across portfolio sections.

## Usage

1. Clone or download the repository.
2. Open `index.html` in your browser.

## Tech Stack

- HTML
- CSS
